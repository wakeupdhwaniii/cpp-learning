# C++ and robotics

A place for small programming exercises inspired by robotics and Aero.

Ideas to explore:

- Variables: store a simulated sensor reading.
- Conditions: choose an expression after a simulated touch.
- Loops: check simulated surroundings repeatedly.
- Functions: separate sensing, deciding, and reacting.

These are planned exercises. Hardware-specific programs should document the board, wiring, dependencies, and how to run them.
